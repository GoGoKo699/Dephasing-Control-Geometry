# Focused verification

This deterministic suite checks constants and channel conventions in [the constructions](../science/constructions.md). It uses dense Lindblad matrix exponentials and Fréchet derivatives of those exponentials. It does not numerically optimize controls or stand in for the analytic converse.

## Run

The suite was tested with Python **3.12.14**, NumPy **2.3.5**, and SciPy **1.17.0**. Only the latter two packages are required; their tested versions are pinned in [requirements.txt](requirements.txt).

From the repository root:

```sh
python -m pip install -r verification/requirements.txt
python verification/run_all.py
```

The runner can also be invoked by absolute path from another working directory. It exits nonzero on a failed comparison. To retain a machine-readable report:

```sh
python verification/run_all.py --output /tmp/dephasing-control-verification.json
```

No files are generated by the default invocation. The optional output records the observed runtime versions and numerical values. Results are compared with the stored analytic values in [expected_results.json](expected_results.json), with absolute tolerance $5\times10^{-11}$ and relative tolerance $2\times10^{-10}$. Last-digit differences across compatible numerical libraries are expected.

## What is checked

### 1. Two commuting noise operators

Four levels have noise coordinates

```math
(-1,0),\quad(1,0),\quad(0,\tfrac12),\quad(0,2).
```

The direct endpoint cost is $4$; the path through the third level costs $5/2$. At $\Omega=1$, the predicted transfer-error derivatives are $\pi/4$ and $5\pi/32$. The numerical derivatives are obtained directly from matrix-exponential derivatives at zero noise, without a finite-difference step.

At two nonzero noise strengths, dense evolution is compared with the closed-form two-level success-product formula. Forward transfer and both inputs of the three-pulse endpoint swap are included. The constructed errors are also checked against the duration-uniform lower bound.

### 2. Uniform ladders and logical Choi weights

For one diagonal jump with eigenvalues uniformly spanning $[0,1]$, the suite uses $m=1,2,4$ gaps and phase-free pulses. It checks the entire ideal endpoint-transposition unitary, including the returned interior levels, as well as the pulse count, duration, and spectral halfwidth.

The first derivative of the projected, ideal-corrected logical Choi matrix is evaluated. Its $Z$, $Y$, $X$, and leakage coefficients are compared with the formulas in [constructions.md](../science/constructions.md#6-logical-phase-transverse-and-leakage-weights). The off-diagonal Pauli-process derivative is checked to vanish. Choi weights use a normalized maximally entangled input and are **not conditioned on remaining in the code**.

### 3. Controlled logical gate

A control qubit conditions a three-gap endpoint swap. The ideal action on the four logical code states is checked against CNOT. Each pulse's halfwidth is $1$, while its displayed operator norm is $2$; this detects accidental substitution of one resource convention for the other.

The noise includes target dephasing and independent control-$Z$ dephasing with reference rate $0.2$. Control-zero truth-table rows remain correct, and control-one rows obey the target path product. Both the finite-noise errors and their first derivatives are checked. This verifies population accounting; it does not assert that the single-logical-qubit phase coefficients also describe CNOT's Pauli components.

### 4. Continuous one-jump correction with retained workspace

The four-qubit, twelve-pulse circuit in [workspace.md](../science/workspace.md) is checked using 16-dimensional unitaries. The suite verifies the compiled five-gate Toffoli on its complete Hilbert space, ideal data CNOT and clean workspace return, nine CNOT and three controlled-half pulse counts, total duration $21\pi/(4\Omega)$, spectral halfwidth, and the aggregate target mixing block.

For a target-$Z$ jump inside each pulse, conjugation by its remaining angle lies in the span of three fixed operators: $P_0Z$, $P_1Z$, and $P_1Y$. All other $Z$ jumps commute with that pulse. The suite transports each of the resulting **72 coefficient operators** through the full circuit and checks that every data Kraus block is diagonal after removing the ideal CNOT. This checks the whole continuous-angle span, rather than sampling jump times. The signed rotation identity is also evaluated directly, including the inverse controlled-half pulse.

A midpulse single-jump witness leaves the data correct while changing the workspace syndrome from 00 to 11. A two-jump witness has average data truth error $1/2$ and non-$Z$ Pauli-process weight $1/2$, independently checking the weight identity with a nonzero error. This is a bounded algebraic/matrix audit of the one-jump boundary; it does not integrate a large Lindblad problem or sweep noise strengths.

## Files and independence of the checks

- [quantum_channels.py](quantum_channels.py) contains generic finite-dimensional channel, pulse, and Choi calculations.
- [cases.py](cases.py) specifies the three small physical examples.
- [workspace_case.py](workspace_case.py) specifies the single additional coherent-workspace boundary example.
- [expected_results.json](expected_results.json) stores values derived from the analytic formulas, including zeros and ideal resource counts.
- [run_all.py](run_all.py) compares the independently evaluated dense evolution with those values.

The expectations are not regenerated from the observed outputs. No random seed, external data, network access, plotting package, or test framework is needed. The largest Lindblad calculation has an eight-dimensional Hilbert space; the workspace audit uses sixteen-dimensional unitaries and finite operator spans.

The suite cannot establish the infimum over arbitrary controls, duration uniformity for every trajectory, asymptotic hardware feasibility, or novelty relative to prior literature. Those claims require the proofs, stated access assumptions, and literature assessment.
